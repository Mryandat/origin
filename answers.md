1. Ветки: изоляция кода. main остаётся стабильным, можно работать параллельно и безопасно экспериментировать.

2. Merge Conflict: Git не может сам объединить изменения, когда в двух ветках правили одни и те же строки одного файла. Решается вручную.

3. Fast-forward vs 3-way: Fast-forward просто двигает указатель вперёд (линейная история, если в main не было новых коммитов). 3-way создаёт отдельный коммит слияния (если изменения были в обеих ветках).

4. Fetch vs Pull: fetch только скачивает изменения, не трогая твой код. pull скачивает и сразу вливает их в текущую ветку.

5. Pull Request: это код-ревью и защита main. Прямой пуш может сломать проект, а PR позволяет проверить код, прогнать тесты и обсудить правки до слияния.
